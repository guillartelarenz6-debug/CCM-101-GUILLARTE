## Analysis Questions

1. **Which cloud provider offers the broadest range of services?**  
   AWS offers the broadest and deepest range of cloud services, spanning compute, storage, databases, serverless, IoT, and machine learning. Its long market head start has allowed it to build the most extensive feature catalog in the industry.

2. **Which provider best integrates with Microsoft technologies?**  
   Microsoft Azure provides unmatched integration with Microsoft technologies like Windows Server, Microsoft 365, and Active Directory. Organizations heavily invested in Microsoft environments benefit from familiar management tools and hybrid licensing discounts.

3. **Which provider is strongest in Artificial Intelligence and Kubernetes?**  
   Google Cloud Platform (GCP) leads in AI and Kubernetes technologies due to Google's role in creating Kubernetes and pioneering deep learning frameworks. GCP offers cutting-edge tools like Vertex AI, BigQuery, and Google Kubernetes Engine (GKE).

4. **Which cloud platform would you personally choose and why?**  
   I would personally choose AWS due to its mature ecosystem, massive global community, and extensive documentation. Learning AWS provides high market versatility and access to the widest variety of cloud architecture patterns.
