# Laboratory 02 – Build the Cloud Infrastructure Blueprint

## Mission Overview

This laboratory activity focused on understanding the main components of cloud infrastructure. I investigated a Linux server using the KillerCoda Playground and examined its computing, storage, networking, and operating system resources.

## Objectives

The main objectives of this activity were to understand cloud infrastructure components, investigate a Linux cloud server, compare cloud service providers, create a simple cloud architecture, and improve my technical documentation skills.

## Cloud Infrastructure Components

The major components investigated were:

- Compute Resources
- Storage Resources
- Networking Resources
- Operating System

These components work together to provide the resources required to run cloud applications and services.
